# 豆角 AI 工具与本地 MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Provide a usable local MCP endpoint that external AI clients can discover and call, with host-controlled tool permissions, bounded call history, and a real image/screenshot → offline OCR → Markdown workflow.

**Architecture:** An Electron-independent registry provides validated tool execution to both MCP and trusted host UI. A loopback Streamable HTTP server uses the official TypeScript MCP SDK. Electron adapters own screen capture, image selection, OCR models and artifacts, Markdown files, persistent settings, and confirmations. Plugins contribute narrow declarative operations rather than receiving privileged Node access.

**Tech Stack:** Electron, TypeScript, React, Node test runner, @modelcontextprotocol/sdk 1.32.1, Tesseract.js 7.

- OCR model download is explicit setup; recognition uses prepared local models and always terminates its worker. No external AI model/key is required for MCP itself.
