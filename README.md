## ✨ 核心理念与架构

豆角工具箱采用**插件化微内核架构（Plugin-Microkernel Architecture）**：
- **纯净微内核宿主**：宿主仅负责窗口管理、权限沙箱、跨源网络代理、底层驱动与安全调度，安装包精简原生；
- **沙箱隔离与安全性**：每个插件均运行于独立的沙箱容器（`sandbox: true + contextIsolation: true`），通过专用 `doujiao-plugin://<pluginId>/` 协议加载资源，严格阻断跨域越权与路径遍历风险；
- **官方 Ed25519 签名体系**：插件市场包分发采用 Ed25519 私钥签名与宿主公钥验签机制，杜绝中间人劫持与篡改；
- **全主题自适应引擎**：内置主题穿透引擎，无论亮色（Light）还是暗色（Dark）模式，均可自动为所有插件提供极致质感的视觉体验；
- **本地隐私数据零泄露**：便签、Markdown 文档、相册人脸识别聚类均在用户本地运行与落盘，无中心化云端遥测，隐私绝对安全。

## 🧩 18 款全量插件矩阵

豆角工具箱内置丰富而专业的日常工具矩阵，涵盖多媒体处理、文件管理、开发者工具与效率协作等：

### 1. 📸 时光相册 `time-album`
基于端侧边缘 AI 的智能多媒体家庭相册管理工具。
- **本地 AI 人脸识别聚类**：纯离线边缘端运行，自动识别人脸特征并聚类分组，支持人物相册重命名与合并；
- **EXIF 时光轴画廊**：精准解析相机机型、曝光参数与拍摄时间，按年/月生成精美回忆时光轴；
- **「那年今日」历史回忆**：自动挖掘往年同日的珍贵相片生成横幅轮播展示；
- **混合云源无缝挂载**：支持本地硬盘目录与 S3 / MinIO / OSS 远程云存储无缝挂载，切换数据源时自动冷热清理缓存。

### 2. 🤝 远程协助 `remote-assist`
面向公网跨设备桌面协助的高性能双向远程支持工具。
- **9 位设备码安全互联**：基于 ECDSA 身份公钥派生 9 位设备代码，带校验位防输错，无需复杂网络配置；
- **公网即连零端口监听**：客户端零入站端口暴露，告别防火墙弹窗；P2P 直连优先，复杂 NAT 智能中继回退；
- **有人值守双端核对**：严格有人值守授权确认，连接时两端显示相同 6 位安全核对码，有效防止中间人冒充；
- **WebRTC 低延迟串流**：动态帧率、分辨率调节，画质平滑自适应；
- **Win32 独立输入安全隔离**：独立 C++ 辅助进程通过命名管道受控注入键盘鼠标，物理鼠标移动 1.5 秒硬件级抢占熔断；
- **多维度紧急熔断**：屏幕顶部悬浮断开条、系统托盘一键断开、全局系统紧急热键（`Ctrl+Alt+Shift+Esc`）；
- **双向文件互传与跨设备剪贴板**：支持文件夹递归传输、大文件断点分块校验与双向剪贴板同步。

### 3. 📝 轻便记事本 `notepad`
专业便签管理工具，集成 AES-256 全局主密码硬件级安全加密。
- **AES-256-GCM 强加密**：便签正文通过 PBKDF2 + AES-256-GCM 强加密存盘，密码学零泄露设计；
- **离开防窥自动上锁**：切换便签或离开时自动加密写盘并重新上锁，再次查看必须输入主密码；
- **加锁便签防误删保护**：删除任何受保护的加密便签必须输入密码验证；
- **多级层级子目录归档**：支持在工作目录下创建树状子文件夹归档便签；
- **本地历史版本快照**：自动记录历史编辑快照，支持时间轴 Diff 差异对比与一键恢复。

### 4. 📄 Markdown 编辑器 `markdown-editor`
专业 Markdown 写作与知识管理工具。
- **三模式自由切换**：编辑模式、实时预览模式、左右双栏分屏模式无缝切换；
- **富文本排版引擎**：语法高亮、GitHub Flavored Markdown 表格、KaTeX 数学公式、图片拖拽与粘贴插入；
- **树状多级目录侧边栏**：支持以本地文件夹为工作区，自由新建、重命名、拖拽移动文档；
- **版本控制快照**：自动快照记录 + 里程碑标记 + Diff 对比与一键还原。

### 5. 🗄️ Samba 文件管理 `samba-manager`
专业 NAS / Samba 局域网网络存储管理器。
- **连接管理**：支持多连接配置（IP、端口、用户名、密码、Workgroup/Domain），完备支持 NTLMv2 认证；
- **流式大文件传输**：流式上传与下载，支持 GB/TB 级别大文件无卡顿传输；
- **智能帧缩略图**：内置 FFmpeg 主进程视频关键帧提取与本地缓存；
- **HLS 在线流式播放**：视频即点即播，无需等待整片下载。

### 6. 🪣 对象存储管理 `object-storage`
多云统一对象存储客户端。
- **全兼容 S3 存储体系**：支持 AWS S3、MinIO、阿里云 OSS、腾讯云 COS、Cloudflare R2 等主流对象存储；
- **宿主网络代理免 CORS**：由宿主主进程转发 API 请求，无需繁琐配置存储桶 CORS 跨域规则；
- **丰富文件操作**：目录树浏览、多文件拖拽批量上传、预签名分享链接一键生成；
- **多媒体即时在线预览**：支持高清图片缩放旋转、音视频倍速播放、PDF 内嵌渲染与代码语法高亮。

### 7. ⚡ 局域网快传 `lan-transfer`
零安装局域网跨设备极速互传助手。
- **手机免装 App 扫码即传**：手机扫描电脑端屏幕生成的二维码，浏览器即可与电脑双向极速收发文件；
- **跨设备文本与剪贴板**：支持跨端文字即时收发，手机复制、电脑一键粘贴；
- **多重安全保护**：PIN 码动态鉴权、多网卡与虚拟网卡智能识别切换。

### 8. 🎵 抖音视频下载 `douyin`
无水印抖音多媒体高清下载工具。
- **全类型解析**：支持单视频、主页作品、合集与专题批量解析；
- **高清原画与图集打包**：支持无水印高清原画一键下载、图文图集自动打包 ZIP；
- **批量任务队列**：支持多链接批量解析与下载队列管理。

### 9. 📺 B站视频下载 `bilibili`
Bilibili 高清视频与音轨下载工具。
- **BV/AV 智能解析**：一键识别 BV 号、AV 号及分享短链接；
- **最高高清画质**：最高支持 1080P 及以上高帧率下载，支持 Cookie 导入解锁大会员高码率流；
- **音画自动合成**：内置原生 FFmpeg 引擎，无损自动混流合并音视频轨道。

### 10. 📋 剪贴板历史 `clipboard-history`
系统级剪贴板历史记录管理器。
- **实时捕获**：系统后台监听剪贴板变化，智能去重，支持文本与图像预览；
- **搜索与置顶**：关键词极速过滤筛选，常用重要条目一键置顶收藏；
- **一键写回**：双击即可快速写回当前系统剪贴板。

### 11. 🌐 内置极速浏览器 `browser`
基于独立会话的内嵌多标签轻量浏览器。
- **WebContents 沙箱隔离**：独立渲染进程与网络沙箱，避免插件污染；
- **标签页与书签管理**：多标签自由切换，一键收藏常用开发网站与文档；
- **智能导航**：集成百度、必应、谷歌等多引擎智能寻址。

### 12. ⏺️ 屏幕录制与 GIF `screen-recorder`
面向演示、操作说明与问题反馈的屏幕捕捉工具。
- **灵活录制模式**：支持划选任意局部区域录制，以及指定显示器全屏录制；
- **双格式输出**：支持输出高清 MP4 视频或轻量 GIF 动图；
- **受控参数调节**：帧率、录制时长、鼠标指针显示与 GIF 尺寸可调；
- **纯本地处理**：内置 FFmpeg 受控转码，数据仅保存在本地工作目录。

### 13. 🛠️ 开发者利器 `dev-toys`
程序员日常开发高频辅助工具集合。
- **格式转换与美化**：JSON 格式化/压缩、YAML 与 JSON 双向互转；
- **编解码转换**：Base64 文本编解码、Base64 图片互转预览、URL 编解码；
- **哈希校验**：MD5、SHA-1、SHA-256、SHA-512 文本与文件哈希即时计算；
- **正则测试器**：正则表达式实时匹配测试与高亮分析。

### 14. 📌 屏幕贴图标注 `screen-pin`
桌面置顶贴图与取色标注神器。
- **一键置顶贴图**：截屏后一键固定在屏幕顶层，支持滚轮平滑无极缩放；
- **透明度与鼠标穿透**：自由调节窗口透明度，支持鼠标穿透临摹；
- **高级涂鸦标注**：矩形、椭圆、箭头、自由画笔、马赛克与文字标注；
- **屏幕精确取色**：支持放大镜准星吸取屏幕任意像素色值并复制 HEX / RGB。

### 15. 🏝️ 桌面文件暂存架 `drop-shelf`
桌面边缘轻量滑出式文件暂存中转岛。
- **边缘贴合抽屉**：靠近屏幕边缘自动呼出或收折，不遮挡日常工作；
- **任意拖拽收集**：支持各种文件、文件夹、多选图片直接拖入暂存；
- **随取随用**：支持从暂存架中将文件直接拖拽至微信、浏览器、编辑器等第三方应用；
- **批量打包**：支持将暂存架内的多个文件一键打包导出为 ZIP。

### 16. 🔄 音视频多媒体转换 `media-converter`
基于原生 FFmpeg 的轻量音视频极速转码工具。
- **全格式支持**：支持 MP4、MKV、MOV、AVI、WebM、MP3、AAC、FLAC、WAV 等常见格式；
- **音频独立抽取**：从视频中无损抽取音频轨道；
- **分辨率与质量压缩**：自适应压缩码率，快速缩减视频体积方便网络发送。

### 17. 🔍 OCR 文字识别 `ocr-recognizer`
高效屏幕截图与图片文字识别工具。
- **划选截图识别**：快捷划选桌面任意区域，文字毫秒级快速提取；
- **图像拖入与剪贴板**：支持直接拖入图片或粘贴剪贴板截图；
- **本地 Tesseract 离线引擎**：纯离线本地识别，保障敏感票据与文字隐私；
- **格式化整理**：支持段落自动清洗合并、按行复制与纯文本一键导出。

### 18. 🎨 图片编辑器 `image-editor`
轻巧强大的专业图片处理与标注工具。
- **比例裁剪构图**：支持 1:1、4:3、16:9 及自由比例裁剪；
- **几何旋转与镜像**：90° 顺逆时针旋转、水平翻转、垂直翻转；
- **滤镜与色彩调优**：实时调节亮度、对比度与色彩饱和度；
- **Canvas 高清导出**：保留图片原始分辨率，支持 PNG / JPEG 无损导出。

## 🏗️ 架构与安全模型

```
┌─────────────────────────────────────────────────────────────┐
│                      Host Shell (宿主主窗口)                 │
│  - 侧边栏导航 (Ctrl+B 折叠)     - 插件市场 (Ed25519 验签)      │
│  - 主题穿透引擎 (Light / Dark)  - 自动更新服务 (app-update)    │
├─────────────────────────────────────────────────────────────┤
│                    受控微内核桥接层 (IPC Bridge)             │
│  - 权限契约校验                - 宿主网络代理 (免 CORS)       │
│  - FFmpeg 进程调度             - 原生 Win32 输入注入隔离      │
├─────────────────────────────────────────────────────────────┤
│                     插件沙箱容器 (WebContentsView)           │
│  - contextIsolation: true     - sandbox: true               │
│  - doujiao-plugin:// 安全协议  - @doujiao/plugin-sdk 受控调用│
└─────────────────────────────────────────────────────────────┘
```

| 安全与架构特性 | 说明 |
|----------------|------|
| **微内核隔离** | 插件在独立的沙箱环境中运行，无法直接触碰 Node.js 底层与操作系统 API |
| **受控 SDK** | `@doujiao/plugin-sdk` 提供严格声明的 capabilities 权限，插件必须按需申请 |
| **自定义协议** | 插件静态资源经由 `doujiao-plugin://<pluginId>/` 协议分发，杜绝目录穿越 |
| **Ed25519 签名** | 插件市场所有发布包均带有 Ed25519 数字签名，宿主在安装前强制验证 |
| **隐私数据保全** | 本地便签、Markdown 等数据以物理明文或 AES-256 强加密保存于本地，软件更新卸载不丢失 |
| **主题自适应** | 宿主注入 `LIGHT_THEME_CSS` 动态主题穿透，实现全系统亮色/暗色一致体验 |

## 🚀 快速开始

### 下载与安装

前往 [GitHub Releases](https://github.com/newbee7955/djtools/releases/latest) 下载最新正式安装包 `djtools-Setup-1.0.0.exe`，双击运行安装即可。

### 本地开发与构建

```bash
# 1. 安装全部 Monorepo 依赖
npm install

# 2. 启动宿主桌面开发环境（支持热重载）
npm run dev

# 3. 运行核心单元测试
node --test apps/host/tests/*.mjs
node --test services/remote-assist-signal/tests/*.mjs

# 4. 构建宿主主程序
npm run build:host

# 5. 打包 Windows 安装包 (.exe)
npm run package:win

# 6. 打包并签名指定插件（自动更新 registry 索引）
node scripts/package-plugin.cjs plugins/notepad

# 7. 批量构建所有插件
npm run build:plugins
```
